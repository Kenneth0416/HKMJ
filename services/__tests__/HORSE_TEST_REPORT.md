================================================================================
                    三、ADD_FAAN 模式測試 ⚠️
================================================================================

設定: 每馬 +1番
測試: 3番食糊, 中2馬 → 番數 3→5, base 40→160

【問題分析】

當前代碼邏輯:
1. effectiveFaan = 3 + 2 = 5
2. baseValue = 160 (5番的籌碼)
3. horseBonusPerPlayer = 160 - 40 = 120
4. 每家付 = baseValue + horseBonusPerPlayer = 280

結果: P1 收 840 (3 × 280)

預期行為 (傳統港麻):
- 選項A: 只付新番數的籌碼, P1 收 480 (3 × 160) ← 馬獎已體現在番數中
- 選項B: 同時代碼計算, P1 收 840 ← 當前實現

⚠️ 問題: 代碼將番數增加帶來的籌碼差額再額外計算為「馬獎」
         導致每家付 160(base) + 120(馬獎) = 280
         但 120 其實就是番數增加帶來的差額, 已經在 base 中體現了!

【建議修復】
ADD_FAAN 模式下, horseBonusPerPlayer 應設為 0, 因為馬獎已體現在番數增加中。

| 自摸 P1 胡 3番 中2馬          | P1 收 840 (應為 480)          | ⚠️   |

                    六、封頂測試 ❌
================================================================================

【問題 1: ADD_FAAN + 封頂】

測試: 8番 + 3馬 = 11番, 應封頂至 10番
- 預期: P1 收 3×5120 = 15360
- 實際: P1 收 26880

原因: 封頂雖正確限制 effectiveFaan = 10, 但 horseBonusPerPlayer 仍計算差額
      horseBonusPerPlayer = 5120 - 1280 = 3840
      每家付 = 5120 + 3840 = 8960

【問題 2: MULTIPLIER + 封頂】

代碼中 MULTIPLIER 模式完全忽略 capApplies 設定!

```typescript
case 'MULTIPLIER': {
  // 沒有處理 capApplies!
  const multiplier = 1 + (horseConfig.perHorseValue * horseHits);
  horseBonusPerPlayer = originalBaseValue * (multiplier - 1);
  break;
}
```

### 🔴 P0 - 必須修復

**問題 1: ADD_FAAN 模式馬獎重複計算**

位置: `scoringService.ts:101-112`

當前代碼:
```typescript
case 'ADD_FAAN': {
  let newFaan = rawFaan + (horseHits * horseConfig.perHorseValue);
  if (horseConfig.capApplies) {
    newFaan = Math.min(newFaan, rules.maxFaan);
  }
  effectiveFaan = newFaan;
  const newBaseValue = calculateBaseValue(effectiveFaan, rules.unitPrice);
  horseBonusPerPlayer = newBaseValue - originalBaseValue; // ❌ 這是問題
  break;
}
```

修復建議:
```typescript
case 'ADD_FAAN': {
  let newFaan = rawFaan + (horseHits * horseConfig.perHorseValue);
  if (horseConfig.capApplies) {
    newFaan = Math.min(newFaan, rules.maxFaan);
  }
  effectiveFaan = newFaan;
  horseBonusPerPlayer = 0; // ✅ 馬獎已體現在番數增加中
  break;
}
```
